# Café Rosa

A simple HTML5/CSS website for the Café Rosa client brief.

## Structure

- `index.html` — Home
- `menu.html` — Menu and prices
- `about.html` — Café story
- `contact.html` — Contact form and address
- `css/style.css` — site-wide layout and formatting
- `images/` — reserved for café imagery

## Brief requirements covered

- Semantic HTML5: `header`, `nav`, `main`, `footer`
- Required header/nav/content/footer dimensions and colours
- Four-page navigation
- Review-site link opens in a new tab
- Menu uses a table because the brief specifically requests item, size and price columns
- Menu includes a back-to-top anchor
- Simple hover brightening effect
- Responsive layout for phones
- Warm, informal independent-café styling
